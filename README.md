# Alibaba.com 直通车投放与店铺经营数据大屏（对外演示版）

> **已脱敏**：本仓库隐藏 GMV 金额、商品 ID、广告计划 ID。曝光 / 点击 / 访客 / 询盘 / 商机 / 订单 / 渠道结构等指标的相对关系保持真实，用于演示"如何用数据判断投放好坏"的分析框架。

在线预览：**https://mawenjian51-byte.github.io/alibaba-ads-dashboard-demo/**

数据窗口：2026-08-12 ~ 2026-11-08（89 个自然日），生成于 2026-11-10。

## 大屏内容

1. **数据概览（总）** — 访客 / 曝光 / 点击 / 直通车点击 / 自然点击 / 询盘 / TM / 及时回复率 / 商机 / 订单 / 广告消耗
2. **直通车投放状态** — 全站推 vs 标准推 双卡对照 + 计划清单（状态 / 预算 / 在线商品数）
3. **按周消耗与转化** — 自然周维度明细与趋势
4. **流量参谋 · 流量来源渠道** — 搜索 / 推荐 / 榜单 / 店内 / 直接访问 / 站外 / 其他
5. **商品参谋** — 每个链接在全店的表现（126 个链接，可排序、搜索、按层级筛选）
6. **商品结构** — 优品 / 爆品 / 潜力优品 / 普通品 / 低质品分层
7. **市场分布** — 欧美买家数据 + 国家 Top 20
8. **运营判断框架** — 8 个判断问题 + 5 条优先动作 + 全站推/标准推可见性对比

## 交互

右上角三种日期操作：快捷「近 7/14/30 天/全部」、起止**日期范围**选择、**单日**跳转。任一改动后 KPI、趋势图、漏斗、周度表、渠道表全部联动重算。

## 这份数据说明了什么

- **直通车处于"停机"状态**：近 90 天广告消耗 ¥0。全站推 4 个计划中 3 个已暂停、1 个"预算花完/账户冻结"；标准推 38 个计划中 4 个在投，其中 3 个在线商品数为 0；标准推近 90 天报表 0 行。
- 店铺侧自然流量仍在运转：曝光 78,096 / 点击 1,869 / 访客 1,309（日累计）/ 商机 437 / 订单 23；访客→商机 10.89%，5 分钟回复率 43.64%。
- 商品结构：优品 3、爆品 0、潜力优品 39、普通品 82、低质品 2 —— 优品储备不足时，应先做品再加预算。

## 技术说明

单文件 HTML，数据内嵌，无 CDN、无外部请求、离线可用。

## 口径

- 访客 / 询盘人数 / TM 咨询人数为上游**日去重**人数，跨日相加不等于区间去重，页面标「日累计」。
- 商品参谋为搜索口径单日明细（快照日各链接搜索曝光合计与店铺当日搜索曝光一致，已对账）。
- 上游仅返回 126 个链接（店铺有效商品 274 个）；访客明细接口在部分区间覆盖不可用，国家维度采用买家分布接口。
